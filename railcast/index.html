Railcast

нояб. 11 2026

Привет!

Сегодня очень короткий пост про мою новую поделку.

Уже где-то пару лет я пользовался приложением Raycast на маке. Это более современная альтернатива стандартному Spotlight и более продвинутому Alphred. Когда я устанавливал Raycast я ддумал что накручу туда побольше плагинов и буду юзать его на полную катушку. Но по итогу оказалось что юзкейса у меня всего два - панелька с быстрым выбором emoji 🤫 и плагин Google Translate.

Остальное оказалось просто не нужно.

Так вот, плагин Google Translate довольно сильно подтормаживал по непонятным причинам. Вставляешь текст, ждешь и ничего не происходит.

В итоге я решил навайбкодить нативную и легковесную замену для Raycast ограниченную только необходимым функционалом. Новую аппку назвал скромно - Railcast! 🤣

Сперва я хотел попробовать в деле Rust + GPUI Kit, но для конкретно этого приложения это не самая подходящая технология. UI тут простой. Рендерить огромные объемы данных не надо. Поэтому был выбран самый простой и нативный способ для macOS - Swift + SwiftUI.

По итогу все очень быстро сгенерировал в Claude Code и затестил. Приложение работает быстро и делает ровно то что мне нужно. В следующей версии также был добавлен поиск по приложениям для их быстрого запуска. Главное отличие от той же фичи в Spotlight - отсутствие поиска по файлам. Поиск только по списку установленных приложений!

Google Translate минималистичный. Умеет только в переводы Ru => En и En => Ru.

Вот собственно и весь фунционал.

Установленное приложение занимает 1.6 мб вместо 160 в Raycast.

Юзаю уже второй день и доволен 🙂

Ссылка на GitHub repo - https://github.com/rhamdeew/railcast
